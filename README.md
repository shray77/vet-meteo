# ВЕТРАДАР-61

Ветеринарный ГИС-прототип оценки эпидемиологических рисков Ростовской области:
гиперлокальный климатический движок + математические модели + OSINT.

## Что внутри

- **Климатический движок**: Open-Meteo (прямой запрос из браузера → прокси
  `/api/meteo` → синтетический фолбэк; бейдж источника в шапке), METAR
  NOAA (6 станций вокруг области через `/api/metar`, кэш 10 мин), открытые
  MQTT-брокеры из Shodan/Censys (вкладка OSINT, ключи юзера).
- **Топография**: псевдо-DEM 0.1° → уклон/экспозиция, застой холодного
  воздуха (корыто рельефа), ветровая экспозиция; микроклимат-поправки к
  T/RH/ветру по каждой точке.
- **Модели**:
  - THI КРС (потери удоя 0.25 кг/ед. выше 72);
  - BRD-скоринг телят 0–100 (амплитуда T, сырость, застой/сквозняк, похолодание);
  - Клещи: GDD₁₀ Hyalomma/Dermacentor → риск КГЛ (эндемичные районы севера
    области) с поправкой на сухость (VPD);
  - Фасциолёз: влагостат Σ(P − 0.8·ET₀), ET₀ по Hargreaves;
  - АЧС: suitability-сетка (лес+вода−город) → Дейкстра → коридор волны
    кабана 12 км/ночь × 20 ночей + официальные кольца 5/20/100 км.
- **UI**: Leaflet-карта (OpenTopoMap/тёмная Carto), слои THI/METAR/реки/
  АЧС-коридор/КГЛ-районы/OSINT, лента триггеров, почасовой THI-график,
  датчики, вкладки Сводка/Прогноз/АЧС/OSINT, диалог формул.

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint
```

OSINT CLI (ключ юзера, в репозиторий не попадает):

```bash
python tools/osint_cli.py --demo                     # демо-выгрузка
python tools/osint_cli.py --provider shodan --key KEY
python tools/osint_cli.py --provider censys --key API_ID --secret SECRET
```

## Честность данных (важно)

- **Очаги АЧС, реки, леса, рельеф — ДЕМО/приближения**, помечены в UI.
  Прод-замена: SRTM 30 м (DEM), OSM waterways (реки), ВетИС «Сирано» /
  пресс-релизы РСХН (очаги), Landsat/ESA WorldCover (леса).
- Коэффициенты моделей — литературные значения, нужна калибровка по
  данным конкретного хозяйства.
- Ключи Shodan/Censys вводятся в UI разово и не сохраняются; сервер
  передаёт их только в запрос к провайдеру.

## Замечание про Leaflet

Leaflet ≥1.8 вшивает флаг Украины в дефолтный префикс атрибуции. Здесь
префикс заменён чистой ссылкой на leafletjs.com (BSD-заслуги сохранены),
плюс CSS-страховка `.leaflet-attribution-flag { display:none }`.

src/lib/                  — metar, synthetic, field-data, assessment
